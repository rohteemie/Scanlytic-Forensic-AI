Package overview

Scanlytic Forensic AI packages the core forensic pipeline as a Python module and CLI. The project emphasizes transparent analysis, local-first processing, and evidence-grade reporting.

Install

git clone https://github.com/rohteemie/Scanlytic-Forensic-AI.git
cd Scanlytic-Forensic-AI
pip install -r requirements.txt

PyPI publishing is planned. Until then, install from source.

Quick run

python -m scanlytic analyze /path/to/file
python -m scanlytic analyze /path/to/dir --recursive

CLI output includes classification, score, and report pointers.
