Overview

Scanlytic Forensic AI is an open-source digital forensic triage system that shortens the time between evidence acquisition and actionable insight. It is designed for security teams in regulated environments who need transparent, auditable results without compromising data residency.

Faster investigations

Reduce manual triage by ranking files using explainable scores.

Evidence-grade outputs

Reports capture the key indicators and context needed for case files.

Local-first privacy

Files stay on your infrastructure. External intelligence is optional.

Capabilities for every engineering team

Designed as a pipeline architecture with clear separation of concerns, making it easy to test, scale, and integrate into existing incident response workflows.

Feature extraction engine

Static analysis for PE, ELF, documents, and scripts with hash computation, entropy, metadata inspection, and suspicious string detection.

Malicious intent scoring

Weighted scoring model that blends rule-based indicators with optional local AI scores to surface the highest-risk artifacts.

Batch and parallel workflows

Analyze directories at scale with tuned worker pools, suitable for large evidence sets or incident response sweeps.

Reporting and audit trail

Structured exports for SIEM ingestion, timeline analysis, and case reporting workflows.

Architecture highlights

Scanlytic Forensic AI follows a pipeline architecture with explicit stages for validation, classification, feature extraction, scoring, and report generation.

01

Intake and validation

Safely validates paths, file sizes, and permissions before analysis.

02

Classification

Determines file category and mime type to route extraction logic.

03

Feature extraction

Captures entropy, hashes, headers, strings, and metadata signals.

04

Scoring

Scores intent with configurable thresholds and optional local AI blending.

05

Reporting

Exports structured output for evidence, triage, and compliance needs.

Getting started

Use Docker for a quick evaluation or install locally for deeper integration.

Quick Docker run

docker build -t scanlytic .
docker run -v /path/to/files:/data scanlytic analyze /data --recursive

Local install

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m scanlytic analyze /path/to/file
