Security posture

Scanlytic Forensic AI prioritizes safe file handling, local processing, and auditability. External integrations are optional and always user-controlled.

Safe file handling

Validates paths, enforces size limits, and never executes files.

Input validation

Verifies magic numbers, sanitizes paths, and applies boundary checks.

Privacy by design

No telemetry or personal data collection. Data remains local by default.

Audit readiness

Deterministic reports, structured outputs, and clear logging options.

Compliance alignment

Designed with GDPR and ISO 27001 principles in mind.

GDPR

Data minimization, local processing, exportable evidence.

ISO 27001

Access controls, secure operations, and risk management focus.

Secure defaults

Conservative settings with optional external integrations.
