Quick start

Set up the repo locally in minutes and run your first analysis.

Recommended setup

git clone https://github.com/rohteemie/Scanlytic-Forensic-AI.git
cd Scanlytic-Forensic-AI
./scripts/setup-dev.sh
source .venv/bin/activate

Run analysis

python -m scanlytic analyze /path/to/file
python -m scanlytic analyze /path/to/dir --recursive

Docker option

Fast evaluation without local dependencies.

docker build -t scanlytic .
docker run -v /path/to/files:/data scanlytic analyze /data --recursive
